# 管理平台交接说明

本目录是 Vue 3 + Vite 管理端。

```powershell
pnpm install
pnpm dev
```

要求：Node.js 20.20+、pnpm 10.17.0。开发代理将 `/api` 转发到 `http://localhost:8080`。

已完成：管理员登录、页面框架、真实运营概览、最近订单、资源新增编辑上下架、SKU 新增编辑、日期库存初始化、库存调整、管理员订单查询、订单详情、超时订单扫描、退款审核、电子核销、用户与会员查询、用户详情和账号启用/禁用、文章发布管理、首页轮播管理、经营数据报表和 CSV 导出、平台参数、角色权限矩阵和操作审计。

未完成：真实管理员账号登录、数据库权限点的逐接口拦截、真实支付退款渠道。会员等级和成长值当前读取已有会员账户数据，积分规则和自动升级规则尚未进入本阶段。轮播图片当前使用 URL，需在对象存储接入后补充上传控件。当前报表为实时查询，数据量增大后需增加汇总表或离线统计任务。

完整状态、接口和交付注意事项见上级目录的 `项目当前进度与交接说明.md`。
