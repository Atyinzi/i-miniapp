# 文创商城 Web 管理端开发计划

## 阶段1：商品与分类管理（已完成）

- 文创商城侧边栏菜单及独立路由。
- 分类列表、新增、编辑、排序、父级分类和启停。
- 商品分页、关键词/分类/状态筛选。
- 商品新增、编辑、封面、轮播图、详情、市场价、重量和上下架。
- 新商品初始 SKU，已有商品 SKU 新增、编辑、启停、价格和预警阈值。
- 分页、加载态、错误提示、成功提示和响应式布局。

验收：`pnpm build` 成功，页面请求与 `/api/v1/admin/cultural-store` 商品分类接口一致。

## 阶段2：库存管理（已完成）

- 库存总览、低库存筛选和搜索。
- 单 SKU 入库、出库、退货、报损、盘点调整。
- 批量入库/出库表格与整批提交。
- 库存流水、操作备注、业务单号和预警状态。

验收：库存调整方向与后端规则一致，所有写操作自动生成 `Idempotency-Key`，`pnpm build` 成功。

## 阶段3：营销管理（已完成）

- 满减、折扣活动列表、新增和编辑。
- 活动时间、优先级、互斥、叠加及适用范围配置。
- 优惠券模板、发行数量、领取限制和有效期。
- 指定用户发券及优惠券状态查询。

验收：折扣输入可自动换算为后端 0—1 小数；已发放优惠券模板锁定经济字段；管理端生产构建通过。

## 阶段4：订单履约与售后（已完成）

- 文创订单工作台、订单详情和地址快照。
- 备货、单笔发货、批量发货、运单修改和物流轨迹。
- 物流异常、确认收货及自动收货状态展示。
- 售后审核、拒绝、退货签收、模拟退款完成和状态流水。

验收：订单、物流和售后管理接口已接入；操作状态与后端流转规则一致；管理端生产构建通过。

## 阶段5：运营报表（已完成）

- 运营指标卡、销售/退款趋势和热销商品排行。
- 售后类型与状态统计。
- 库存货值、低库存分析和库存变动趋势。
- 销售明细 CSV 导出。

验收：报表日期范围与后端最长 366 天规则一致；销售明细使用后端 CSV 导出接口；管理端生产构建通过。

## 延后事项

- 真实微信支付及原路退款管理功能待后端支付渠道接入后实施。
