# 部署、运维与操作手册（初稿）

## 1. 部署前置条件

- JDK 17、MySQL 8.0+、Redis 7+；生产环境使用独立账户、独立数据库和 TLS。
- 环境变量：`DB_URL`、`DB_USERNAME`、`DB_PASSWORD`、`REDIS_HOST`、`REDIS_PORT`；支付、短信等密钥不得写入代码或配置仓库。
- 首次部署前创建 `iminiapp` 数据库，字符集使用 `utf8mb4`；Flyway 执行 `src/main/resources/db/migration` 中的版本脚本。

## 2. 当前启动步骤

1. 配置数据库和 Redis 环境变量。
2. 执行 Maven 构建，启动 Spring Boot 应用。
3. 查看应用健康检查、数据库迁移日志和 Redis 连通性。
4. 导入微信小程序工程，替换正式 AppID 和后端 HTTPS 地址。

> 管理端、反向代理、对象存储、日志采集和正式 HTTPS 证书尚未实现，正式部署手册必须在这些能力完成后补全可复制的命令、配置与回滚步骤。

## 3. 运维基线

- 监控：应用存活、接口错误率与延迟、数据库连接数、慢 SQL、Redis 命中率和磁盘空间。
- 日志：按日期滚动，包含 `traceId`；不得记录密码、支付密钥、完整身份证号码或电子核销明文码。
- 备份：每日增量、每周全量；至少每季度进行一次恢复演练并记录恢复时间。
- 变更：数据库迁移先在测试环境验证；生产变更需保留发布包、迁移版本和回滚方案。

## 4. 管理员与用户操作手册的前期目录

管理员：登录与权限、轮播/公告管理、资源与库存、订单/退款、核销、报表、日志。
用户：登录、服务浏览、预订/购票、支付、查看订单、取消/退款、电子码核销、反馈。

正式操作手册应在页面及权限完成后，以实际界面截图和真实操作步骤编写，避免与最终产品不一致。
