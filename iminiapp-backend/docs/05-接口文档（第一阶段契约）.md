# i某小程序 - 接口文档（第一阶段契约）

状态：接口契约已确定，服务端尚未实现。正式实现时必须以 OpenAPI 3.0 文档同步发布。

## 通用约定

- 基础路径：`/api/v1`
- 编码：UTF-8 JSON；金额字段均为整数分。
- 认证：用户接口使用 `Authorization: Bearer <accessToken>`；匿名首页接口不需要令牌。
- 成功响应：`{"code":"OK","message":"success","data":{},"traceId":"..."}`。
- 失败响应：`{"code":"INVENTORY_409","message":"库存不足","data":null,"traceId":"..."}`。

## 1. 获取首页聚合数据

`GET /api/v1/home`

用途：小程序首页在首屏一次取得轮播、快捷入口、特色服务、公告和公开平台设置。

响应示例：

```json
{
  "code": "OK",
  "message": "success",
  "data": {
    "banners": [{"id": 1, "title": "线上购票，无需排队", "imageUrl": "https://cdn.example/banner.jpg", "targetType": "SCENIC", "targetId": 101}],
    "quickLinks": [{"id": "hotel", "title": "客房", "icon": "hotel", "path": "/pages/hotel/index"}],
    "coreServices": [{"id": "north-hotel", "title": "示例宾馆", "subtitle": "会议、住宿、餐饮一站式预订", "path": "/pages/north-hotel/index"}],
    "notice": {"id": 11, "title": "示例宾馆新增会议室预约优惠"},
    "servicePhone": "400-XXX-XXXX"
  },
  "traceId": "c1e1b5d0"
}
```

## 2. 资源列表

`GET /api/v1/resources`

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `type` | string | 否 | `HOTEL_ROOM`、`MEETING_ROOM`、`SCENIC_TICKET` 等 |
| `keyword` | string | 否 | 名称关键词，最大 50 字符 |
| `page` | integer | 否 | 从 1 开始，默认 1 |
| `pageSize` | integer | 否 | 1-50，默认 20 |

## 3. 创建订单

`POST /api/v1/orders`，需登录。

请求示例：

```json
{
  "orderType": "HOTEL",
  "items": [{"skuId": 2001, "quantity": 1, "serviceDate": "2026-08-01", "timeSlot": ""}],
  "clientRequestId": "9f06766a-c0f8-4ed0-9818-7b3e6e0e44f1"
}
```

`clientRequestId` 用于客户端重试幂等；后端应在同一用户范围内保证其唯一。成功时返回订单号、金额、支付截止时间和订单状态。

## 4. 核销电子码

`POST /api/v1/verifications/consume`，需核销权限。

请求：`{"code":"用户展示的明文电子码"}`。响应返回 `verificationId`、`status`、`verifiedAt`；已核销码返回可识别的业务错误，不重复核销。

## 5. 提交意见反馈

`POST /api/v1/feedback`，需登录。

请求：`{"content":"建议增加周末场馆预约", "contact":"138****0000"}`。内容最大 500 字符，后端过滤危险输入并限制频率。
