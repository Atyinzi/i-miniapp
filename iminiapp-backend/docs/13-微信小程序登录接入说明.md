# 微信小程序登录接入说明

## 已完成的后端流程

1. 小程序调用 `wx.login()` 获取一次性 `code`。
2. 小程序把 `code` 发送到后端微信登录接口。
3. 后端请求微信 `code2Session`，换取 `openid`、`session_key` 和可选的 `unionid`。
4. 后端根据 `openid` 建立稳定的内部用户编号。
5. 后端在 Redis 中签发 8 小时登录令牌。
6. 后续请求继续使用统一的 `Authorization: Bearer <token>`。

登录响应不会返回 `openid`、`session_key` 或 AppSecret。

## 后端配置

推荐在 IDEA 的 `IminiappBackendApplication` 运行配置中添加环境变量：

```text
WECHAT_APP_ID=微信小程序AppID
WECHAT_APP_SECRET=微信小程序AppSecret
```

修改后必须重新启动后端。禁止把真实值写入 GitHub 中的 `application.properties`。

也可以复制 `application-local.properties.example` 为被 Git 忽略的 `application-local.properties`，然后只在本机填写。

## 后端接口

```http
POST /api/v1/app/auth/wechat-login
Content-Type: application/json

{
  "code": "wx.login返回的一次性code",
  "displayName": "用户显示名称"
}
```

成功后返回结构与模拟登录一致：

```json
{
  "code": "SUCCESS",
  "message": "微信登录成功",
  "data": {
    "accessToken": "bfa_...",
    "tokenType": "Bearer",
    "expiresAt": "时间",
    "user": {
      "userId": "wx-内部编号",
      "displayName": "用户显示名称",
      "accountType": "USER",
      "roles": ["ROLE_USER"]
    }
  },
  "traceId": "请求追踪编号"
}
```

## 小程序端调用示例

```javascript
wx.login({
  success(loginResult) {
    wx.request({
      url: 'https://你的后端域名/api/v1/app/auth/wechat-login',
      method: 'POST',
      data: {
        code: loginResult.code,
        displayName: '微信用户'
      },
      success(response) {
        wx.setStorageSync('accessToken', response.data.data.accessToken)
      }
    })
  }
})
```

`code` 只能使用一次，而且有效时间很短。不要把旧 code 固定写入 `api-examples.http` 重复测试。

## 当前可测试范围

没有真实 AppID/AppSecret 时，可以运行 `WechatLoginServiceTests`，验证身份映射、隐私保护和 Token 签发。

提供真实配置后，使用微信开发者工具运行小程序，由 `wx.login()` 获取实时 code，再调用后端接口完成真实联调。

## 安全要求

- AppSecret 只允许保存在后端环境变量或密钥管理系统中。
- 小程序前端不得保存或传输 AppSecret。
- 后端日志不得输出 AppSecret、session_key、openid 或完整 Token。
- 真实微信用户在数据库使用微信 openid 关联；模拟用户继续使用 `mock:` 隔离标识。
