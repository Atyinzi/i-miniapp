# 餐饮预订模块四阶段完成记录

## 阶段 1：门店、菜品与库存（已完成）

- 门店、餐位/雅间、菜品分类、菜品图片与详情、原价/特价、推荐菜和上下架。
- 套餐及套餐菜品组成维护；菜品实时库存、锁定库存、可售库存、预警阈值和批量入库/出库流水。

## 阶段 2：预订与点餐交易（已完成）

- 支持堂食、到店自提、外卖三种履约方式，支持餐位/雅间、就餐时段、人数、配送地址和组合点餐。
- 服务端价格快照、套餐库存展开、下单锁库存、支付扣库存、取消/超时释放库存。
- 餐位数据库行锁、容量校验和严格时间区间冲突检查，防止超订。
- 复用现有模拟在线支付，正式微信支付按既定计划后续接入。

## 阶段 3：订单、后厨、退款与核销（已完成）

- 用户订单列表、待支付取消；已支付订单接入统一退款申请、审核及回调流程。
- 支付后实时生成后厨和前台任务，支持新任务、接单、备好、完成状态流转。
- 餐饮专用核销码、到店扫码、重复核销保护和履约完成；外卖支持配送完成。

## 阶段 4：Web 管理端与营业报表（已完成）

- Web 管理端提供门店、餐位、分类、菜品、套餐和库存维护，订单、后厨/前台、核销与报表工作台。
- 营业总览包含订单、营业额、就餐人次、核销、取消退款、菜品/套餐销售；支持销量排行和 UTF-8 CSV 导出。
